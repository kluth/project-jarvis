JARVIS is a standalone, omni-architecture programming language and execution substrate. It is designed to bridge human intent and autonomous AI execution with mathematical certainty.

## 🚀 Key Features
- **Omni-Architecture:** Target any device from microcontrollers to cloud nodes via **TG-IR**.
- **eTDD (Enforced TDD):** Compilation fails if logic is not verified by a mandatory `verify` block.
- **PDD (Performance-Driven Development):** Static Big-O proofs for every function.
- **AI Symbiosis:** Autonomous repair loops via the **Multi-Agent Gateway (MAG)** and **MCP Server**.

## 🛠 Substrate Architecture
The **Jarvis Universal Runtime (JUR)** is a `no_std` hardware-agnostic substrate.
- **Wait-Free Scheduler:** $O(1)$ cooperative dispatcher.
- **RCU Allocator:** Epoch-based zero-lock memory management.
- **HAL Layer:** Thin hardware abstraction for zero-copy stream mapping.
